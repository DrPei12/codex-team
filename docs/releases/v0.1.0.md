# Codex Team 0.1.0 — Initial public workflow

## New Features

- **Seven Team skills**: Plan, prepare, observe, integrate, finish, recover, and route a manifest-driven Codex engineering run.
- **Evidence-bound handoffs**: Bind workspaces, revisions, reports, Gate logs, and reviewer decisions instead of relying on worker prose.
- **Relocatable plugin**: Build a deterministic skills-only `codex-team` plugin with a SHA-256 bundle manifest and self-check.
- **Repository marketplace**: Install and remove the plugin through a local Codex marketplace with documented rollback.

## Evidence and limits

The offline workflow and a controlled install/discovery cycle were verified. The seven skills remain `incubating`; this release does not prove stable live worker dispatch, long-term routing accuracy, automatic cleanup, or a background scheduler.
