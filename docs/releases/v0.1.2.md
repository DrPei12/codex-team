# Codex Team 0.1.2 — Task lifecycle and localized titles

## New Features

- **User-language task titles**: Visible task titles are separate from prompts and carry a manifest locale.
- **Execution surfaces**: Distinguish sidebar-visible tasks from one-shot internal subagents.
- **Lifecycle policy**: Mark lanes as one-shot, milestone, or long-lived owner.
- **Finish dispositions**: Recommend archive, retain, or not-applicable per lane without performing destructive cleanup.

## Breaking Changes

- Manifests, briefs, dispatch bundles, and finish artifacts gained required lifecycle fields. Older runtimes must not be assumed compatible.

## Evidence and limits

Source and temporary package tests passed, and one controlled rename/archive sweep was observed. Automatic archive, handoff, cleanup, and long-term title-language accuracy remain unverified.
