# Codex Team 0.1.4 — Windows path alias compatibility

## Bug Fixes

- **Portable status validation**: Team status now accepts a file and allowed artifact root that use different Windows short/long aliases when both resolve to the same real directory.
- **Escape protection retained**: Real paths outside the allowed root continue to fail closed.

## Evidence and limits

The affected local suites passed: team-status 24/24, packaged plugin 9/9, and the offline end-to-end schema flow 1/1. The full Windows CI run is the independent public release Gate. This release does not add a live fact collector, scheduler, automatic task interruption, or new product capability.

## Known issue

The public CI run showed that Python `realpath` alone did not normalize every Windows `RUNNER~1` workspace alias. Worker preflight could still report `workspace path mismatch`. Version 0.1.5 replaces existing-directory text comparison with filesystem identity checks; the 0.1.4 tag remains unchanged.
