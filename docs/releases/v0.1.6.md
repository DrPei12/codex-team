# Codex Team 0.1.6 — Unified Windows path identity

## Bug Fixes

- **All candidate phases**: Integration and recovery candidates now compare existing workspaces by filesystem identity.
- **Reviewer lineage**: Integration plan, candidate, and apply workspace paths use the same identity rule while branch, base revision, mode, and cleanliness fields remain exact.
- **One shared rule**: Plan, run, status, integrate, and recover no longer maintain inconsistent short/long path comparisons.

## Evidence and limits

Nine local suites passed 148 tests and the offline flow validated 16 end-to-end artifacts. Public main and tag CI runs are the release Gate. This release does not add a live fact collector, scheduler, automatic task interruption, or cleanup authority.

## Known issue

The public CI run passed workspace identity but exposed lexical-only containment for candidate report/evidence refs under a short-path run root. Version 0.1.7 unifies all run/artifact containment checks; the 0.1.6 tag remains unchanged.
