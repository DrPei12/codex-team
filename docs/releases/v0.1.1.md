# Codex Team 0.1.1 — Integration identity hardening

## Improvements

- **Consistent ownership**: A bare repository-relative ownership path now covers the path and its descendants across plan, integrate, and recover. Explicit glob behavior remains segment-aware, and forbidden paths always win.
- **Exact reviewer target**: Reviewer preflight now binds the canonical dispatch, integration plan/apply receipt, passed Gate, real Git merge topology, and post-integration commit/tree.

## Breaking Changes

- Ownership matching and reviewer preflight semantics changed. Do not overwrite or reuse a cached 0.1.0 package under the same version identity.

## Evidence and limits

The repaired paths passed source fixtures and packaged offline integration tests. This release did not yet establish a new Desktop reviewer forward test or a stable version-upgrade/cache behavior.
