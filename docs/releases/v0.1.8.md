# Codex Team 0.1.8 — UTF-8 Windows release Gate

## Bug Fixes

- **Unicode-safe CI output**: Windows CI explicitly enables Python UTF-8 mode and UTF-8 stdio, so successful commands can report Unicode paths without a cp1252 encoding failure.

## Evidence and limits

The code and artifact protocol are unchanged from 0.1.7; nine local suites passed 149 tests and the offline flow validated 16 end-to-end artifacts. Both public main and tag CI runs must pass the full suite and plugin self-check. This release does not add a live fact collector, scheduler, or task mutation authority.
