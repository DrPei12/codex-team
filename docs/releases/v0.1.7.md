# Codex Team 0.1.7 — Unified run and artifact containment

## Bug Fixes

- **All artifact references**: Reports, evidence, candidates, proofs, Gate receipts, status facts, finish inputs, and router paths now use one resolved containment rule.
- **Future outputs**: Nonexistent output files bind through their nearest existing parent, preserving no-escape behavior without relying on short/long display text.
- **Cross-phase consistency**: No Team phase retains an independent lexical-only run-root containment check.

## Evidence and limits

Nine local suites passed 149 tests and the offline flow validated 16 end-to-end artifacts. Public main and tag CI runs are the release Gate. This release does not add a live fact collector, scheduler, automatic task interruption, or cleanup authority.

## Known issue

The public CI run passed finish and integration, then a successful team-plan projection failed while printing a Unicode path through the runner's cp1252 stdout. Version 0.1.8 makes Python UTF-8 I/O explicit in CI; the 0.1.7 tag remains unchanged.
