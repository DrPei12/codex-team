# Codex Team 0.1.5 — Filesystem identity on Windows

## Bug Fixes

- **Workspace aliases**: Existing workspace, Git root, and common-directory paths now compare with `os.path.samefile`, handling Windows short/long path names by filesystem identity.
- **Artifact containment**: Existing paths walk resolved parents and use the same identity check, while paths that really escape the allowed root remain rejected.

## Evidence and limits

The release adds a real NTFS short-path workspace preflight regression and extends the artifact-alias check. Nine local suites passed 146 tests and the offline flow validated 16 end-to-end artifacts. Public Windows CI remains the independent release Gate. No live fact collector, scheduler, or automatic task mutation is added.
