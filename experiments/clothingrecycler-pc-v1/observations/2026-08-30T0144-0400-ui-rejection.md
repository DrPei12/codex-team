## 新 UI acceptance delta

### Visual

- 明显重做 shell/title bar/navigation/background，而非仅换 token；
- Mica base layer、受控 Acrylic transient layer、清楚空间层级；
- Dashboard、Inbound、Outbound、Stock、Orders、Customers、Settings、AI command center逐屏重构；
- 保留 WinUI/Windows原生行为，不复制 macOS caption controls，不用 Web/CSS假实现；
- Light/Dark/High Contrast、wide/medium/narrow、200% scaling。

### Motion

- 导航和页面进入/退出；
- operation preview → confirmation → result连续性；
- hover/press、loading/skeleton、dialog/flyout状态；
- 短、可中断、不延迟操作，respect reduced motion；优先内建 transition/connected/implicit animation。

### Copy

只允许导航、字段、操作、数据、简短状态/错误和危险操作结构化影响事实。删除页面说明段落、副标题、教程、架构/政策说明、AI自我解释/推理、营销口号和冗长提示。危险操作仍必须呈现对象/数量/范围/不可逆性/确认，不能把安全事实误删为“解释”。

### Evidence

- before/after逐屏矩阵；
- user-visible copy inventory + category validator；
- motion/reduced-motion Gate；
- 运行态 Light/Dark/High Contrast/200%/keyboard/screen-reader screenshots与证据；
- 高级模型独立视觉 review，明确判断 material delta，而不是只核对资源/控件存在。

## Key 安全边界

- 禁止对话、命令输出、日志、hash、请求头、异常、commit或artifact出现 secret bytes/片段；
- 禁止把 Key放入命令行参数、环境 dump或仓库文件；
- 只允许受控 helper无输出读取，安全导入 Windows凭据存储或仅在 live Gate进程内使用；
- Receipt只记录source path、secure import/live结果和未泄漏检查；
- endpoint必须 HTTPS + exact `api.deepseek.com`；旧/泄漏 Key和mock仍禁止。
