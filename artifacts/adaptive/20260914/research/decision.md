# 个人研究资料的可追溯保存方案

**默认采用：链接＋关键摘录。**

- **仅保存链接**：成本、维护量和敏感信息暴露最低；但链接可能失效，且稳定 URI 不等于内容不变，日后无法证明当时看到的版本。
- **链接＋摘录**：用适量原文保留依据，成本适中，适合作为默认；缺点是摘录脱离上下文，页面下线后不能恢复全文。
- **链接＋原文快照**：最有利于找回全文、比对版本；但占空间、泄露和版权风险更高，动态脚本、表单、流媒体、登录区等也可能无法完整保存。仅对高价值、易下线、快速变化或可能引发争议的材料升级使用，并只保存研究所需范围。

**最小记录字段**：标题；作者/机构；原始 URL；访问时间（含时区）；发布日期/版本（若有）；关键摘录及位置（页码、章节或段落）；保存方式与范围。保存快照时再记捕获时间、SHA-256 和版权/敏感信息备注。哈希只能帮助判断字节是否变化，不能判断语义变化。

**敏感边界与局限**：不保存密码、Cookie、登录态、表单输入、无关个人信息及未经授权的受限内容；快照先裁剪。私下保存不等于获得复制、公开或再发布许可。快照只是捕获时点的副本，不保证完整、可交互或永久可读；链接、摘录和哈希都不能替代必要的定期复核。

**一手来源**：W3C《[Common HTTP Implementation Problems](https://www.w3.org/TR/chips/)》第4节说明 URI 可保持稳定而内容仍会变化；美国国会图书馆《[Web Archiving 指南](https://www.loc.gov/acq/devpol/webarchive.pdf)》说明快照受爬虫、动态内容、登录区及版权/权限限制。
